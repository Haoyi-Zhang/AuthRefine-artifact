# Third-party materials

The repository includes selected upstream source snapshots only where they are needed to define or replay a study boundary. Their original licenses, notices and snapshot identities remain next to the source or in `external_inputs/` and `source_study/source/`. The project license does not replace those upstream terms.

The native and source-level studies are reproducibility material, not vendored runtime dependencies for AuthRefine itself. Exact optional Python dependencies are installed from the pinned requirement files; they are not copied into this repository.
