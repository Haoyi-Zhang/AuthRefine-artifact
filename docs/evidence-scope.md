# Evidence scope and repository status

## What the artifact establishes

The current self-contained release checks complete diagnosis for a supplied, finite family of fixed correspondences over deterministic finite interfaces with the declared state observation and admitted caller language. It independently checks retained/excluded members, per-member shortest witnesses, replay fields, active-support grouping, and the finite caller constructions used by the paper.

The fresh campaign reexecutes 10,000 primary finite cases, the exhaustive 23,040 policy-machine domain, adversarial controls, the two-session motivating example, selected source bodies, and the prospective source-transfer set. The source and native records are kept separate from synthetic finite cases; retained native and timing records are not described as fresh executions.

## Strong evidence

- Independent direct semantics and product search cross-check the production implementation.
- Fault controls alter support, traversal, observations, request sequences, and replay data; the checks reject or diagnose these changes.
- The exhaustive finite domain covers every declared policy-machine pair in that domain, not a sample.
- The prospective source-transfer set is project-disjoint from the construction set and preserves its own source and license boundaries.
- The complete-output timing comparison compares the same per-binding classifications and replay rows across methods.

## Boundaries that remain part of the scientific claim

- The correspondence family is supplied; the project validates and diagnoses it but does not infer a complete family for arbitrary applications.
- The finite theorems do not prove the entire Python implementation for unbounded state spaces.
- The prospective source-transfer set is source-level evidence without a human-reviewed whole-application gold standard.
- Native framework, CUDD, and Lean environments require their exact external toolchains. A retained record is not a fresh run.
- The fixed benchmark cohorts support algorithmic trade-offs on those cohorts, not a universal performance ranking.
