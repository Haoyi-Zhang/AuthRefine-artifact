# AuthRefine figures

The paper and supplement contain sixteen figures: six mechanism diagrams and
ten quantitative plots. All are generated by Python as vector PDFs, using the
manuscript's Linux Libertine text and LibertineMathMI mathematical fonts,
black and gray marks, and labels sized for the journal column. Primary labels
and ticks are 10--11.3 pt; mathematical subscripts retain their normal scale.
The diagrams use explicit coordinates
and checked relations; statistical plots read retained observations and timings.

The overview follows four fixed bindings through the active-support operation.
Its worked partition comes from `src/diagnostic_example.py`: the bindings form
two groups at request `a`. One group stays active and splits at request `b`,
while the other yields two individual fixed-binding replays. Matching requires
the complete graph check, indicated separately from the two illustrated cells.
Algorithm 1 and the protocol algorithm specify validation, initial comparison
and admission order.

The session lifecycle and credential handoff diagrams read native observations
and retained source records. They check the common prefixes, distinct outcomes
and fixed interpretations before drawing. The native session-family figure
uses the same unified timing campaign as the complete-family cost and symbolic
comparison figures. Their shared loader checks all 5,320 timing records against
the raw worker outputs, including the exact seven repetitions, method/task
denominators and complete-output identities. The complete-family cost figure
uses the 38 state/support and earlier source tasks. Three common-axis panels
separate the 27 sparse tasks by failure behavior; seven dense/singleton tasks
and four source/control tasks use individual rows. Each task appears once. The
session figure plots the unmodified-source cases, and the cumulative comparison
shows every task in all three cohorts separately.

## Regenerate the figures

Install ReportLab and PyMuPDF. Put the manuscript's Linux Libertine TeX fonts on
the `kpsewhich` search path, or set `AUTHREFINE_TEXMF` to their TeX font tree.
The same font tree supplies LibertineMathMI for mathematical labels. From `artifact/`:

```sh
python3 -B figures/regenerate.py --output-directory /path/to/fresh-figures
```

The destination must be new. The command runs all six renderers, checks the
sixteen-file figure set, opens and renders each PDF, verifies embedded fonts and
vector content, and checks that its inputs did not change during generation.
Scientific observations and timing measurements are read, not rerun. The
executable two-stage example is checked while it is drawn.

After inspecting the generated figures, copy their PDFs and data sidecars to
`paper/figures/`. Copy `family-cost-rows.tex` separately to `paper/`. The figure
commands do not silently replace manuscript tables. The cost renderer also
accepts an explicit `--table-output` destination.

Individual renderers are available for focused changes:

```sh
python3 -B figures/draw_evaluation.py --output-directory /path/to/output
python3 -B figures/draw_schematics.py --output-directory /path/to/output
python3 -B figures/session_lifecycle.py --results results/native-session --output /path/to/output/session-lifecycle.pdf --svg /path/to/output/session-lifecycle.svg
python3 -B figures/family_cost.py --results results/symbolic-comparison --output /path/to/output
python3 -B figures/session_correspondence.py --results results/session-correspondence --comparison-results results/symbolic-comparison --output /path/to/output
python3 -B figures/symbolic_comparison.py --results results/symbolic-comparison --output /path/to/output
```

All three cost renderers interpret `--output` as a directory. The lifecycle renderer
uses `--output` for one PDF. Its optional SVG is exported from the same checked
vector page, so the two formats preserve the same content.

## Reading the timing plots

The complete-family figure uses the ratio of two seven-run medians. Its
whiskers span `[min(product)/max(grouped), max(product)/min(grouped)]`; this is an
observed-run envelope, not a confidence interval. Sparse tasks occupy three
facets with common logarithmic call-ratio and time-ratio axes. Dense/singleton
and source/control panels use the same logarithmic time-ratio scale and one
categorical row per task. No point is moved or jittered to separate task groups.

The native session-family figure uses absolute elapsed diagnosis time. Symbols
are seven-run medians; intervals are the observed minimum and maximum.
The two methods occupy separate positions within the same session-count row;
vertical displacement is only a method key. Diagnostic timing includes validation and normalization of the supplied
family, graph construction, comparisons, indexes and every individual witness
replay. Native observation acquisition, enumeration of candidate permutations
and output serialization are outside that clock. The third panel repeats the
six-session unrestricted result and adds the two other caller languages.

The symbolic comparison uses the same seven-run medians for each task and
normalizes scan, finite-domain diagram and CUDD times by support-indexed time.
Ratios below one mean the compared method is faster on that task. Each panel
is an empirical cumulative distribution with its own stated denominator:
38 state/support and earlier source tasks, 40 session/caller tasks, or 80
policy-file/caller tasks. Caller languages and initial stores do not represent
independent applications. The cumulative curves summarize this fixed cohort;
they are neither confidence intervals nor estimates of deployment frequency.
Line style distinguishes the three methods in the monochrome plots.
The time axes include all measured ratios and are shared across the panels.
No decision-diagram operation count is equated to a concrete reference call.

## Export high-resolution and portable vector assets

The paper includes the PDF originals, which have no fixed raster resolution.
An explicit Unicode map preserves copied mathematical variables while retaining
the exact manuscript glyphs. All stroked paths are at least 0.6 pt at native
figure width. To export the same sixteen originals for reuse:

```sh
python3 -B figures/export_assets.py --input-directory ../paper/figures --output-directory /path/to/fresh-exports
```

The export contains 600 dpi PNGs and SVGs with outlined manuscript glyphs.
The supplied copies are in `paper/figures/exports/`. No font installation is
needed to view the outlined SVGs; the Python source remains the editable master.
The record accompanies every export with its source and dimensions.

## Inspect the compiled figure atlas

Build the main paper and supplement, then run from `artifact/`:

```sh
python3 -B figures/build_atlas.py --output ../paper/figure-atlas.pdf --build-summary ../paper/build-logs/build-summary.json
```

The atlas checks the final manuscript inputs and the actual figures consumed
by TeX. It resolves figure numbers and page locations from the compiled
auxiliary files, then verifies their visible captions in the PDFs. A stale
input or incomplete build stops atlas creation.

Each atlas page shows the original vector figure at its declared journal width
and a grayscale rendering of the same figure. Main-paper and supplementary
figure numbers remain distinct. The atlas is a visual index; it introduces no
additional experiments or measurements. Inspect figures in the actual PDF
pages as well as the atlas to check caption placement, surrounding text and
page balance.
